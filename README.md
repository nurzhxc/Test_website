Это мой учебный проект на Django, который я сделал в 15 лет. Здесь реализовано регистрация,вдох в аккаунт, размещение/удаление и изменения новостей на сайте.
Также в разделе контакты есть рабочие разные ссылки.В разделе Новости можно открывать статьи так же доступная кастомизация статей.
На главной странице имеется кнопка авторизации после нажатия которой перекидывает на страницу с авторизацией
На странице с авторизацией доступна кнопка с созданием аккаунта если его нет
На странице с регистрацией так же имеется кнопка если аккаунт уже есть и нужно просто авторизоваться
Страница про нас к сожалению пустует
Делая этот проект я использовал Bootstrap и fontawesome.com 
К сожалению сайт не открывается по ссылке я прикреплю скриншоты с сайта
